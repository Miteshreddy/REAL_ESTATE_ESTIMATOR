## Supporting folders

| Folder | Contents |
|---|---|
| `manifests/` | CSV / JSON inventories, all regenerated by `python ml/evaluation/build_reports_v2.py` except the hand-built `manual_acquisition_queue.csv`. Additional files: `category_coverage.csv`, `zip_v2_derivative_inventory.csv` |
| `logs/` | test run, scorecard run, leakage check, acquisition decisions, discovery log, validation log, runtime smoke test |
| `diagrams/` | Mermaid sources |
| `evidence/` | `facts.json` (the numbers used in every report), pytest JUnit XML, contact sheets, classifier spot-check, permission-request template |
| `scratch_archive/` | scratch inventory plus copies of small historical documents |

The datasets themselves are in `tn_corpus/` and `data/tn_dataset/`, never in this folder.
